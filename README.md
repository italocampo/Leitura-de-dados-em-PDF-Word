# Leitura de Dados em PDF e Word – Python

## 📌 Sobre
Este projeto tem como objetivo **extrair e ler dados de arquivos PDF e Word (.docx)** usando Python. A ideia é automatizar a leitura de documentos para uso em análises, extração de informações importantes ou processamento de texto.

## 🚀 Funcionalidades
- Ler texto de arquivos **PDF**
- Ler texto de arquivos **Word (.docx)**
- Retornar o texto extraído para uso em scripts ou análises
- Pode ser usado em automações ou integração com outros sistemas

## 🛠️ Tecnologias
- Python  
- Bibliotecas populares como:
  - `PyPDF2` ou similar para PDF
  - `python-docx` para Word
  - Outras dependências conforme a necessidade
